# راهنمای صفحه‌کلید فارسی در سیمرغ‌اواس

## چیدمان پیش‌فرض

سیمرغ با دو چیدمان فعال می‌شود:

- **انگلیسی (us)** — پیش‌فرض
- **فارسی استاندارد (ir / pes)** — مطابق استاندارد ISIRI 9147

جابه‌جایی: **`Super + Space`**

نشانگر چیدمان فعال در Waybar و LightDM دیده می‌شود.

## نیم‌فاصله

در چیدمان فارسی: **`Shift + Space`** (مطابق xkb استاندارد ir).

## ارقام فارسی

ارقام ردیف بالای صفحه‌کلید در چیدمان فارسی، ارقام فارسی (۱۲۳…) تولید می‌کنند.

## افزودن چیدمان سوم

اگر چیدمان دیگری می‌خواهید، در `~/.config/hypr/hyprland.conf`:

```
input {
    kb_layout = us,ir,de
    kb_options = grp:win_space_toggle
}
```

## fcitx5

برای ورودی پیشرفته (مانند ایموجی یا آوانویسی)، `fcitx5` نصب است:

```bash
fcitx5-config-qt
```
